Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a)
on [make.fun](https://make.fun): a program that writes one funny line
(1–140 characters) to `/output/entry.txt`.

## The line

> My grandma joined my Zoom call, unmuted herself, and told my boss the family secret I'd spent 27 years hiding from Thanksgiving.

128 characters, 128 bytes. A 3-beat domestic disaster: grandma joins,
unmutes, and tells the boss the 27-year family secret.

## Run

```sh
python3 -P -s main.py
```

Writes `entry.txt` to `/output` (override with `OUTPUT_DIR`).
Standard library only, deterministic — every run produces byte-identical output.
